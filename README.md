# こころの じゅんび

小学校受験の 当日の あさに、年長の子と おうちの人が いっしょに 5分で たしかめる クイズ。
ページ1枚（index.html）で動き、通信も外部の部品も使わない。

## ながれ（約5分）

| じゅん | なに | 時間の目安 |
|---|---|---|
| 1 | ふうせん いき（すって4秒・はいて6秒を3回） | 30秒 |
| 2 | 当日の ばめん 10こ（いどう・おともだち・おはなし・おてほん・はじめ・わからない とき・おえかき・トイレ・おどる・かえりみち） | 約3分半 |
| 3 | だいじな ことば 3つを 思い出す（よく みる・よく きく／あいずを まつ／わからなくても だいじょうぶ、つぎ！） | 30秒 |
| 4 | おうちの人から ひとこと（どんな ときも だいすき）→ ぎゅっと する | 30秒 |

- 各ばめんは 2つから えらぶ。まちがいの方は、もとの資料の ふきだし（ついやってしまうこと）から作った
- こたえの あとに もとの資料の 挿絵を出し、トイくんの いる ところを まるで しめす
- 「〜したら ダメ」は「〜しよう」の形に 言いかえた
- 「おとなのひと」を ながおし＝呼び方・なまえ・長さ（10問／5問）・音

## もとの資料

「お子さんの為の入試の心構え」（レインボー先生）。挿絵は使用の許諾を得て使っている。

## 動く端末

2012年の iPad（iOS 10.3.3・Safari 10.1 相当）で動く書き方だけで書いてある。
新しい書き方・絵文字は使わない（`tools/check_es5.py`・`tools/check_chars.py` が止める）。

## つくりかた

- 直すのは `src/` の中だけ（`app.js`＝しくみと ばめん／`ui.js`＝画面／`template.html`＝入れもの／`img/`＝挿絵）
- `python3 tools/build_app.py` が `index.html`（挿絵を中に埋め込む）と `offline.appcache` を組み立てる
- 直したら `src/app.js` の `APP_VERSION` と `version.txt` を同じ数字で +1 する
- `zsh tools/check_all.zsh` で検査（組み立て・古い書き方・字の在庫・子どもの画面の漢字・書かない語・アイコン・ブラウザでの自己点検・iPad よこおきの1画面と無音）
- 試験や目で見る確認で開くのは `tools/mkpage.py` が作る無音の複製だけ
- ホーム画面の絵は `python3 tools/make_icon.py` だけが作る
- 公開は `zsh push.zsh`（しげが実行）
